# STRATA — The Next Layer of Intelligence

Кинематографичный тёмный лендинг для вымышленной платформы AI-инфраструктуры.
Один файл, ноль зависимостей, ноль сборки — открывается двойным кликом.

**Живая версия:** ссылка появится здесь после включения GitHub Pages.

---

## Идея

`Strata` — геологические слои. Знак-молния в форме «S» читается одновременно
как слои и как разряд энергии, а заголовок «The Next Layer of Intelligence»
превращает это в законченную мысль: не «ещё один AI-сервис», а **следующий
слой** поверх того, что уже есть.

Отсюда и вся визуальная логика: чёрная пустота, приглушённое серебро,
одинокая фигура, идущая к светящемуся порталу. Никаких карточек, градиентных
шаров и фиолетового — только пространство, типографика и одно движение.

---

## Что интересного внутри

### Единицы, привязанные к высоте экрана

Обычный адаптив ломает вертикальный ритм: на низком экране макет уезжает вниз,
на высоком — растягивается. Здесь один «пиксель макета» жёстко привязан к высоте:

```css
--u: calc(100vh / 1058);   /* эталонный холст 1487 × 1058 */
--uw: calc(100vw / 1487);
--h: clamp(var(--u), calc(var(--u) * .65 + var(--uw) * .35), calc(var(--u) * 1.16));
```

Композиция всегда занимает экран ровно так, как задумано: навигация на 27,
заголовок на 230.5, логотипы на 995, низ на 1058. При этом `--h` позволяет
типографике подрасти до +16% на сверхшироких мониторах, но никогда не сжаться.

Результат: на 1487×1058 каждый элемент попадает в измеренную позицию
**с точностью до 0.1 px** — проверено замерами `getBoundingClientRect()`.

### Видео как фон, а не как медиа-блок

Видео растянуто шире экрана и сдвинуто так, чтобы светящийся портал приходился
на правую треть, а левая колонка с типографикой ложилась на чистую темноту.
Поверх — две измеренные маски: нижнее затухание в чёрный (9 контрольных точек)
и боковой леттербокс, обрезающий кадр по краям.

### Три раскладки, один файл

| Режим | Как определяется | Что меняется |
|---|---|---|
| Десктоп | по умолчанию | абсолютные координаты, заголовок в две строки |
| Планшет | `≥600px` + `max-aspect-ratio: 11/10` | поток, две строки, логотипы в ряд |
| Телефон | `max-aspect-ratio: 11/10` | поток, заголовок переносится, логотипы 2×2 |

В портретных режимах единица переключается на ширину: `min(100vw/430, 1.34px)`.

### Мелочи, которые заметны

- Ключевой кадр `riseNav` сохраняет `translate(-50%,-50%)` — центрированная
  навигация не дёргается в конце анимации.
- `translateY(1u)` внутри белых пилюль — оптическая компенсация: текст в
  скруглённой форме кажется приподнятым, если центрировать его математически.
- Появление блоков сдвинуто по времени: знак → заголовок → подпись → кнопки →
  логотипы. Всё отключается при `prefers-reduced-motion`.
- Полная доступность: `aria-expanded`, `aria-hidden`, закрытие меню по Escape,
  видимый фокус, `safe-area` для айфонов с чёлкой.

## Стек

Ничего. Один `index.html` — HTML, CSS и 20 строк JavaScript внутри.

Единственное внешнее — шрифт Manrope с Google Fonts и фоновое видео.
Ни сборщика, ни фреймворка, ни `node_modules`.

---

## Запуск

Откройте `index.html` в браузере. Или локальным сервером:

```bash
python -m http.server 4173
```

---

## Про фоновое видео

Видео подключено по внешней ссылке на CloudFront и **не принадлежит этому
репозиторию** — оно не копируется и не распространяется здесь.

Если ссылка перестанет отвечать, фон станет чёрным, а вся композиция
останется на месте. Для боевого проекта замените `<source src="...">` на своё
видео — лучше положить рядом файл и сослаться на него локально.
